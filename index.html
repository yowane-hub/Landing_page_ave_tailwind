BUSY Bar est un dispositif multi-outil de productivité avec un écran LED pixelisé. Minuteur de cocentration avec fonction de blocage des distractions sur votre téléphone et PC. Entièrement personnalisable, open source et prêt pour la maison connectée.

Outil de productivité

Blocage des distractions, message BUSY personnalisé, minuteur de concentration, synchronisation multiplateforme

Application et intégration

Bibliothèque d'application, connexion à des logiciels tiers, intégration avec les événements de calendrier et les appels

Support maison connéctée

Connectez-vous à Google Home et Apple Home via protocole Matter

Pour les développeurs

API HTTP ouverte, SDK open-source bibliiothèque Python/ Go / Javascript, MQTT, sans verrouillage fournisseur

Montrez que vous êtes occupé

Empêchez les autres d'interrompre votre concentration profonde. L'écran affiche que vous êtes occupé et quand serez à nouveau disponible.

Activation instantannée

Activez et désactivez le statut BUSY manuellement avec un large bouton. Fonctionnement entièrement hors ligne, sans logiciels supplémentaire requis.

Set timer

Set an optional expiration timer BUSY using the scroll wheel to 1st others know when you'll be available again
